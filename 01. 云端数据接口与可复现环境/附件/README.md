# 实验 01 附件与个人修改

主运行入口位于 `coursekit/pipeline.py`。从课程根目录运行 `.\.venv\Scripts\python.exe -m coursekit lab01`。

本目录的 `student_object_roundtrip.py` 是个人修改练习。先完成 identity 登记，再复制到 `submissions/lab01` 并直接运行，保存业务修改前的基线。附件自动读取已登记学号，不需要手改 `STUDENT_ID` 常量；直接执行会原生记录 stdout/stderr、退出码并生成运行 JSON/HTML。然后修改 `make_key()`，再改变一个 payload 数值并逐次比较哈希，提交源码、与原附件的 diff、真实运行结果；不要用示例学号登记身份。

此脚本使用临时 Moto HTTP 模拟器，退出即停止服务；它不是持久云存储。脚本只处理内置的小型 JSON，个人练习不要改写 `data/raw` 中供后续实验使用的原始数据。

输入：脚本内的小型 JSON。输出：终端中的对象键、原始与下载 SHA-256、相等判定。测试凭据 `testing` 只用于本机模拟，不含真实账号权限。

不提交 `.venv`、缓存或测试服务临时数据。报告结构以同级上层的 `实验报告提交及评分标准.md` 为准。

## 身份与运行记录

先登记本人学号。课程入口和本章可执行附件会在真实运行时生成带学号、实验号 **01** 与 `run_id` 的 JSON/HTML；独立命令或预期故障可用 `capture --lab 01` 保存真实输出、错误和退出状态。截图须原生显示本人学号、实验号、`run_id` 与真实结果。缺学号、身份与结果不一致，或没有真实结果的提交不予验收。身份登记只用于标识本人，不能代替实验结果。完整提交方式参照[公共提交与验收规范](../../docs/学号与提交验收.md)。
